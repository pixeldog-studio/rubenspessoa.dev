# rubenspessoa.dev: design rules

The token sheet for the Pixeldog studio site and for `design/rubenspessoa-dev.pen`. The front matter is generated
from what the pages render (`design/tools/pen-baseline/README.md`): capture a local build, run `sync.sh`, and never
hand-edit a value. Code wins ties: `src/styles/site.css` is the whole stylesheet and the source of truth.

## What the code defines

- `:root` custom properties in `src/styles/site.css`, each a `light-dark()` pair: `--bg`, `--ink`, `--ink-soft`,
  `--ink-muted`, `--line`, `--line-soft`, `--card`, `--accent`, `--brand-verdigris`, `--focus`, `--shadow-card`,
  `--icon-ring`, `--icon-shadow`, `--radius` (12 px), `--radius-lg` (20 px), `--measure`, `--wide`.
- Scheme: follows `prefers-color-scheme`, overridable by `data-theme` on `<html>` (the footer toggle). The Pen file
  has light frames and dark frames; each dark frame is an instance of its light frame with the dark theme, so dark
  mode in Pen is exactly the tokens' dark values.
- Type: the system font (`-apple-system` / SF Pro), weights 400–700 including variable steps (550, 590, 650).
  Chrome draws it at an optical size equal to the font size, so the Pen file uses one static-opsz instance per
  size (`SF Pro 17` … `SF Pro 54`, made locally by `design/fonts/install-sf.sh` from `SFNS.ttf`; never committed).
- Wide-gamut: on P3 displays `--accent` and `--brand-verdigris` switch to `color(display-p3 …)`. Captures and
  tokens use the sRGB fallbacks.

## Principles (read from the CSS)

- Quiet paper: warm off-white `bg` with a paper-grain texture, ink text in three steps (`ink`, `ink-soft`,
  `ink-muted`), hairlines at low alpha (`line`, `line-soft`).
- One accent (`--accent`, magenta-red) for focus and hover states only; nothing at rest uses it.
- Cards (`card`, `rounded-lg` 20 px, `elevation.shadow1`) hold each app; app icons are real artwork.
- Measure-limited prose (`--measure` 42 rem) for the legal pages.

## Not in the Pen file

- The paper grain: a fixed `body::before` noise overlay (an SVG turbulence data URL at `--grain-opacity`). Pen
  can't tile it, and it accounts for most of the pixel diff on the first viewport of every page.
- Hover/focus states (the accent colour) and the theme switch's forced light/dark positions: forcing a theme
  overrides `prefers-color-scheme`, and those states look like the light and dark frames with one segment pressed.
- `/de/` and `/pt-br/`: the same layouts as `/` and `/about/` with translated copy.

## Open questions

- 3 `literal-*` colours have no custom property: plain black (#000000), the verdigris page-wash gradient stop (#0EB8B8 at 7%) and transparent.
- 32 spacing values and 14 font sizes come from `rem`/`clamp()` at the three captured widths (1440, 390, 320). Is a fixed scale wanted?
- `hq design tokens-check rubenspessoa.dev` can't read plain `light-dark()` custom properties yet
  (pixeldog-studio/hq#156).

## Anti-defaults (avoid in every design)

- Gradients, glassmorphism, neon; more than one accent; accent used at rest.
- Stock illustrations or generic device mockups in place of the real app icons and screenshots.
